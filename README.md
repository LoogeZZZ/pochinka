# Починка

**Discord, YouTube, игры и Telegram одной кнопкой.**

[⬇ Скачать для Windows](https://github.com/LoogeZZZ/pochinka/releases/latest) · Windows 10/11, x64

---

## Знакомо?

Чтобы в России нормально пользоваться интернетом, сейчас нужен целый зоопарк:

- **zapret** для Discord и YouTube. Это папка с двадцатью `.bat`-файлами: `general (ALT)`, `general (ALT2)`, `general (FAKE TLS AUTO)`… Запускаешь по очереди и гадаешь, какой сегодня работает. Когда выходит новая версия, всё скачиваешь и распаковываешь заново.
- **tg-ws-proxy** для Telegram. Ещё одна программа, которую надо держать запущенной, и ещё одна ссылка, которую надо вставить в настройки Telegram.
- **VPN-клиент** для всего остального: Happ, v2rayN, Hiddify. Подписка, выбор сервера, «системный прокси или TUN?».
- **Конфликты.** Включил VPN — zapret начинает мешать. Забыл выключить один, включил другой, и не грузится ничего. Яндекс и банк открываются через зарубежный сервер и начинают спрашивать капчу.
- **Окно UAC** при каждом запуске. Утром по новой: открыть три программы, нажать три кнопки, проверить, что всё завелось.

Каждая из этих программ хорошая. Вместе пользоваться ими больно.

## Что делает Починка

Собирает всё это в одно окно с одной большой кнопкой.

- **Обход блокировок.** Внутри [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube): программа сама скачивает и обновляет его, а стратегии переключаются в один клик. После включения она проверяет, открываются ли Discord и YouTube, и подсказывает, если нужно сменить стратегию. Есть списки для игр: Valorant, Steam, HoYoverse, гачи и другие, включаются тумблерами.
- **VPN.** Вставляешь ссылку на подписку (Remnawave, Marzban, 3x-ui или просто `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`). Подписок может быть несколько, каждая помнит свой сервер. Есть режим «Авто», который сам выбирает самый быстрый сервер.
- **Telegram.** Встроенный прокси, порт [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy). Нажимаешь «Подключить Telegram», Telegram Desktop спрашивает «Включить прокси?», соглашаешься, и всё. VPN для этого не нужен.

## Без лишних нервов

- **Не мешают друг другу.** Обход и VPN взаимоисключающие: включаешь одно, другое выключается само.
- **Российское идёт напрямую.** Яндекс, банки, Госуслуги и VK никогда не ходят через VPN, поэтому сервисы не видят зарубежный IP. Через VPN идёт только заблокированное, или всё, кроме российского, если так выбрать.
- **Помнит, что было включено.** Закрыл программу или перезагрузил компьютер — при запуске включится то же самое.
- **Автозапуск в трей,** если нужно. Включается в настройках.
- **UAC только один раз,** при установке. Дальше программа запускается без запроса.
- **Предупреждает о чужом VPN.** Если параллельно работает другой VPN в режиме TUN (Happ, v2rayN), Починка скажет об этом, а не будет молча не работать.

## Как начать

1. Скачай `Pochinka-x.y.z.exe` со страницы [релизов](https://github.com/LoogeZZZ/pochinka/releases/latest).
2. Запусти и подтверди запрос администратора, один раз.
   Если появится SmartScreen, нажми «Подробнее» → «Выполнить в любом случае»: exe не подписан.
3. Нажми большую кнопку.

VPN по желанию: стрелка у пункта VPN → вставить ссылку на подписку.

## Частые вопросы

**Зачем права администратора?**
Без них не работают драйвер WinDivert, на котором стоит zapret, и режим TUN. Программа просит права один раз, при установке в `C:\Program Files\Pochinka`.

**Антивирус ругается на zapret.**
WinDivert часто ловят как подозрительный. Добавь папку `C:\ProgramData\Pochinka\zapret` в исключения Защитника.

**Discord или YouTube всё равно не открываются.**
Шестерёнка → «Обход блокировок» → выбери другую стратегию. Применяется сразу, проверка покажет результат.

**Где журнал?**
`C:\ProgramData\Pochinka\logs\pochinka.log` или Настройки → Журнал. Ссылки подписок и ключи из журнала вырезаются, им можно делиться.

## Сборка из исходников

Нужны [Go](https://go.dev/dl/) 1.27+ и [Wails](https://wails.io/) v2.16.

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.16.0
wails build -skipbindings -trimpath -ldflags "-s -w"
```

Готовый exe появится в `build/bin/`. Тесты запускаются командой `go test ./...`.
