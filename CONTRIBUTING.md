# Как помочь проекту

Спасибо, что заглянули! Помочь можно не только кодом.

## Сообщить о проблеме

Создайте [issue](https://github.com/LoogeZZZ/pochinka/issues/new/choose) по шаблону. Больше всего помогают:

- версия Починки (Настройки, внизу) и версия Windows;
- провайдер и регион: блокировки у всех разные;
- что включено: обход, VPN (прокси или TUN), Telegram;
- кусок журнала: Настройки → Журнал, или файл `C:\ProgramData\Pochinka\logs\pochinka.log`. Ссылки подписок и ключи из журнала вырезаются автоматически, но перед отправкой всё равно просмотрите его глазами.

**Не публикуйте** ссылки на подписки, `vless://`-ключи, токены и личные данные.

Уязвимости — не в issue, а приватно, см. [SECURITY.md](SECURITY.md).

## Поделиться рабочей стратегией или доменом

Если у вашего провайдера Discord или YouTube заработал только на определённой стратегии, или игре нужен домен, которого нет в списках, напишите об этом в issue. Это ценная информация для всех.

## Прислать код

1. Сделайте форк и ветку от `main`.
2. Соберите и проверьте:
   ```bash
   go vet ./...
   go test ./...
   wails build -skipbindings
   ```
3. Код форматируется через `gofmt`. Комментарии на русском, в стиле окружающего кода: объясняют «почему», а не «что».
4. Одно изменение — один pull request. Опишите, что и зачем меняется, и как вы это проверили.

### Где что лежит

| Папка | Что внутри |
|---|---|
| `*.go` (корень) | приложение: окно, трей, автозапуск, Telegram |
| `internal/zapret` | установка и запуск zapret, стратегии, игровые списки |
| `internal/vpn` | подписки, xray-core, системный прокси, TUN |
| `internal/tgproxy` | прокси для Telegram (порт tg-ws-proxy) |
| `internal/paths`, `internal/config`, `internal/applog` | папки и права, настройки, журнал |
| `frontend/dist` | интерфейс: HTML, CSS, JS без сборщиков; переводы в `i18n.js` |

### Безопасность — обязательно

Программа работает с правами администратора, поэтому:

- никаких файлов, которые потом исполняются или загружаются, в папках, куда может писать обычный пользователь;
- всё, что приходит из подписки или из сети, — недоверенные данные;
- не запускайте с правами администратора программы, через которые можно открыть произвольный файл (Блокнот, Проводник): ссылки и файлы открываются от имени пользователя.

Если меняете зависимости, пересоберите лицензии: `bash tools/genlicenses.sh`.

## Выпуск релиза (для автора)

1. Поднять версию: `productVersion` в `wails.json` и `appVersion` в `app.go`.
2. Если менялись зависимости: `bash tools/genlicenses.sh`.
3. Собрать: `wails build -skipbindings -trimpath -ldflags "-s -w"`, скопировать в `release/Pochinka-X.Y.Z.exe`.
4. **Подписать:** `go run ./tools/signer sign release/Pochinka-X.Y.Z.exe` → появится `.exe.sig`.
5. Создать релиз `vX.Y.Z` и приложить **оба файла**: `Pochinka-X.Y.Z.exe` и `Pochinka-X.Y.Z.exe.sig`.
   Без `.sig` (или с подписью другим ключом) встроенное обновление откажется ставить версию.

Ключ подписи лежит в `%USERPROFILE%\.pochinka-release\signing.key`, в репозиторий не попадает. Держите резервную копию: без ключа новые версии не подписать.
